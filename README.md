Portfólio Acadêmico - DSM
 
Este projeto é um portfólio acadêmico desenvolvido durante o curso de Desenvolvimento de Software Multiplataforma (DSM) da Fatec Indaiatuba.
 
O objetivo do portfólio é registrar minha evolução durante a disciplina de Algoritmos e Lógica de Programação, mostrando as atividades realizadas, conteúdos aprendidos e eventos que aconteceram durante as aulas.
 
Sobre o projeto
 
O site possui algumas seções:
 
- Início — apresentação do portfólio e da disciplina.
- Sobre mim — informações sobre o estudante e link para o GitHub.
- Diário de Bordo — registro das aulas e dos conteúdos trabalhados.
- Atividades Avaliativas — atividades realizadas durante a disciplina e seus respectivos arquivos.
- Eventos — registro de palestras e visitas realizadas durante as aulas.
 
Tecnologias utilizadas
 
- HTML5
- CSS3
